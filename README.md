# math_modeling
历年竞赛题目与课程练习的建模实践，包含论文报告和完整代码。  
Mathematical modeling practice based on past competition problems and coursework, including reports and code.

## 目录 | Contents

| # | 题目 / Topic | 方法 / Method |
|---|---|---|
| 01 | [运输问题与分配问题](./01_运输问题与分配问题) Transportation & Assignment Problems | 线性规划、匈牙利算法、混合整数规划 |
| 02 | [人口增长模型](./02_人口增长模型) Population Growth Model | 微分方程 ODE、非线性最小二乘 |
| 03 | [差分方程](./03_差分方程) Difference Equations | 差分方程、数值模拟 |
| 04 | [回归分析](./04_回归分析) Regression Analysis | 最小二乘法 OLS、全子集回归 |
| 05 | [CUMCM 1999 A题 自动化车床管理](./05_CUMCM1999_A题) | 随机优化、贝叶斯决策 |
| 06 | [CUMCM 2024 C题 农作物种植策略](./06_CUMCM2024_C题) | 混合整数线性规划 MILP |
| 07 | [嘉应学院数学建模竞赛 物流集包](./07_嘉应学院数学建模竞赛) | 时间序列预测、0-1 规划 |
